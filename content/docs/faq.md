## Apakah developer mode berbayar?

Tidak ada biaya. Syaratnya hanya menyetujui ketentuan penggunaan di Pengaturan > Developer.

## Kenapa key saya tiba-tiba `401`?

Kemungkinannya: key sudah dicabut, kamu keluar dari developer mode, akunmu diblokir, atau key salah ketik. Buat key baru di Pengaturan > Developer.

## Bisakah API dipakai untuk mengirim pesan?

Belum. API v1 bersifat read-only: berita, komentar berita, dan Kritik & Saran.

## Berapa perangkat yang bisa ditautkan?

Maksimal 4 perangkat tertaut. Keluarkan salah satu kalau sudah penuh.

## Kode tautan saya kedaluwarsa

Kode berlaku 3 menit. Pilih **Kode baru** di perangkat yang sedang menunggu.

## Apakah pesan terenkripsi end-to-end?

Belum. Lihat bagian perbandingan di [Arsitektur](/docs/arsitektur).

## Bagaimana melaporkan bug?

Lewat halaman [Kritik & Saran](/cas).
