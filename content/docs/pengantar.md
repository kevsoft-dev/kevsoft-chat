## Istilah yang dipakai

- **Perangkat tertaut**: login tambahan yang disetujui lewat kode, mirip fitur di aplikasi chat besar lain.
- **Developer mode**: status akun yang dibutuhkan untuk membuat API key.
- **API key**: kunci berawalan `kc_live_` untuk memanggil API.
- **Kev-Ai**: asisten AI. Di grup dipanggil dengan `@kev-ai`.

> [!NOTE]
> Semua contoh memakai `https://domainmu.com` sebagai alamat. Di halaman ini alamat itu otomatis diganti dengan alamat server yang sedang kamu buka.
